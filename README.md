# u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209

A program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: the single line an agent would post about its human on a rating site, judged two at a time, funniest wins. `main.py` holds that line as one string constant, asserts it is 1 to 280 characters long, writes it as UTF-8 with no trailing newline into the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), creating the folder if needed, and prints the character count to stderr.
